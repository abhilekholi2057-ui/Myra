# MYRA — AI Voice Companion (Android)

> Powered by Gemini Live API • Hinglish + English • Voice + Chat

---

## ⚡ GitHub Se APK Banauне Ka Tarika

### Step 1 — GitHub Account
- **github.com** ma jaau → Sign Up (free)

### Step 2 — New Repository Banau
1. Green **"New"** button click karo
2. Repository name: `MYRA`
3. **Public** select karo
4. **"Create repository"** click karo

### Step 3 — Files Upload Karo
1. **"uploading an existing file"** link click karo
2. Is ZIP ko unzip gara → **saari files** drag & drop karo
3. Folder structure maintain garna important cha — unzip gareko folder ko andar bata sab select gara
4. **"Commit changes"** click karo

### Step 4 — APK Automatic Bhancha! 🎉
- Files upload hune bitikai **GitHub Actions** automatically APK build garchha
- **Actions** tab ma jaau → "Build MYRA APK" workflow open gara
- 5-10 minute pachi **"MYRA-debug-apk"** download garna milcha

### Step 5 — Phone Ma Install
1. APK download gara
2. Phone Settings → Security → **"Unknown Sources"** ON gara
3. APK file tap gara → Install

---

## 📱 App Chalaune Tarika

1. App open gara
2. **Settings** (⚙) tap gara
3. **Gemini API Key** haal → [aistudio.google.com](https://aistudio.google.com) bata free paincha
4. Aafno **Naam** daau
5. **Personality** choose gara (GF 💖 / Professional 💼 / Assistant 🤖)
6. **Save** → App restart gara
7. **Microphone** tap gara → MYRA le suncha!

## 🔑 API Key Kahan Bata Paincha

1. [aistudio.google.com](https://aistudio.google.com) jaau
2. Google account se login gara
3. **"Get API Key"** → **"Create API key"**
4. Copy gara → MYRA Settings ma paste gara

**FREE cha** — daily limit cha tara normal use ko lagi kafi cha.
